DZ 19:


    1). Для получения адреса объекта используется метод `get_absolute_url()`.
        - `Product.get_absolute_url()` использует маршрут `main:product_detail`.
        - `Category.get_absolute_url()` использует маршрут `main:category_detail`.

    2). Валидаторы установлены на следующих полях:
        - `Product.price` — `validate_non_negative_price`, запрещает отрицательную цену.
        - `Review.stars` — `MinValueValidator(1)` и `MaxValueValidator(5)`, ограничивают оценку диапазоном от 1 до 5.

    3). Метод `Product.discounted_price()` массово изменяет цены платных товаров.
        На странице распродажи применяется скидка 10% ко всем товарам с ценой больше нуля. Обновление выполняется через `bulk_update()`.
        Запустить массовую операцию может только пользователь с `is_staff=True`.

    4). Задание со звёздочкой выполнено полностью:
        Абсолютный адрес товара добавлен в существующий JSON отдельного товара (`api/app/<id>/`).
        Адрес формируется через `Product.get_absolute_url()` и `request.build_absolute_uri()`, поэтому содержит схему и хост текущего запроса.
